6. 💾 GESTION MÉMOIRE
🔧 Fuites mémoire (Priorité HAUTE)
Subscriptions non nettoyées:

// AVANT: Fuite mémoire
ngOnInit() {
this.service.getData().subscribe(data => {
this.data = data;
});
}

// APRÈS: Propre
ngOnInit() {
this.subscription = this.service.getData().subscribe(data => {
this.data = data;
});
}

ngOnDestroy() {
this.subscription.unsubscribe();
}

Objets THREE.js non disposés:

// AVANT: Fuite mémoire
this.scene.remove(object);

// APRÈS: Nettoyage complet
this.scene.remove(object);
if (object.geometry) object.geometry.dispose();
if (object.material) {
if (Array.isArray(object.material)) {
object.material.forEach(m => m.dispose());
} else {
object.material.dispose();
}
}

✅ GAIN: -50% utilisation mémoire, prévention crash navigateur
